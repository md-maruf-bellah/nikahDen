# রাউট ম্যাপ — Nikah Deen (Frontend)

রোল, বিজনেস কনটেক্সট ও মডিউল অনুযায়ী রাউট সাজানো; নেভিগেশন গার্ড ও প্রতিটি পেজে কী দেখা যায় তার সংক্ষিপ্ত মানচিত্র।

## ক্রোম (Navbar/Footer) কোথায় থাকে
`src/components/SiteChrome.jsx` — root layout থেকে সব পেজে **Navbar + Footer** দেখায়, *শুধু* এই রুটগুলোতে লুকায়:

| রুট | কেন লুকানো |
|---|---|
| `/login`, `/register`, `/reset`, `/email` | অথ ফ্লো — মনোযোগী ফর্ম পেজ |
| `/checkout`, `/payment`, `/success` | ট্রানজেকশনাল ফ্লো |
| `/dashboard*` | অ্যাডমিন নিজের সাইডবার-শেল ব্যবহার করে |

## ১. পাবলিক (লগইন ছাড়াই)
| রুট | বিবরণ |
|---|---|
| `/` | ল্যান্ডিং (স্ট্যাটস, সার্চ বার) |
| `/about` | আমাদের গল্প |
| `/contact` | যোগাযোগ ফর্ম → `POST /contacts` (rate-limited, ডুপ্লিকেট-গার্ড) |
| `/list` | বায়োডাটা ডিরেক্টরি — ফিল্টার/সর্ট/পেজিনেশন (শুধু APPROVED) |
| `/details?id=` | বায়োডাটা ভিউ — গেস্টে সারসংক্ষেপ; পূর্ণ ভিউতে connect লাগে (`CONNECTS_INSUFFICIENT` হলে কেনার CTA) |
| `/member` | মেম্বারশিপ প্লানের প্রাইসিং |

## ২. অথ ফ্লো
| রুট | বিবরণ |
|---|---|
| `/login` | ইমেইল-পাসওয়ার্ড + Google/Facebook বাটন (সার্ভারে কনফিগার্ড হলেই সক্রিয়) |
| `/register` | রেজিস্ট্রেশন |
| `/email` | পাসওয়ার্ড ভুলে গেছেন — রিসেট লিঙ্ক অনুরোধ (enumeration-নিরাপদ) |
| `/reset?token=` | নতুন পাসওয়ার্ড সেট — strength মিটার, কনফার্ম ম্যাচ, টোকেন-অবৈধ/মেয়াদ-শেষ বার্তা |
| `/auth/callback?code=` | OAuth রিটার্ন পয়েন্ট — one-time কোড → টোকেন, role অনুযায়ী রিডাইরেক্ট |

## ৩. মেম্বার এলাকা (`/profile` — লগইন + role=USER)
সাইডবার ট্যাব: ড্যাশবোর্ড (প্যাকেজ+কমপ্লিশন) · বায়োডাটা (তৈরি/এডিট/ছবি/জমা) · পছন্দের তালিকা · যারা পছন্দ করেছেন · প্রেফারেন্স ও ম্যাচ · মেম্বারশিপ · নোটিফিকেশন · মেসেজিং · লগআউট।
সহায়ক রুট (মেম্বার কনটেক্সটেই): `/checkout`, `/payment`, `/success`, `/biodata` (উইজার্ড)।

## ৪. অ্যাডমিন এলাকা (`/dashboard` — role ∈ {SUPERADMIN, ADMIN, EDITOR})
ট্যাব: ড্যাশবোর্ড স্ট্যাটস · ইউজার ম্যানেজমেন্ট · বায়োডাটা মডারেশন · ইনভয়েস · সাপোর্ট · নোটিফিকেশন · মেসেজিং।

## ৫. গার্ড-ম্যাট্রিক্স
| পেজ | গার্ড | ব্যবহারকারী যা দেখে |
|---|---|---|
| `/profile` | টোকেন নেই → `/login`; স্টাফ → `/dashboard` | মেম্বার ড্যাশবোর্ড |
| `/dashboard` | স্টাফ না হলে: লগইন থাকলে `/profile`, না হলে `/login` | অ্যাডমিন শেল |
| `/checkout`, `/payment` | টোকেন নেই → `/login` | কেনাকাটা |
| `/biodata` | টোকেন না থাকলে সাবমিটের সময় `/login` | উইজার্ড |

## ৬. OAuth (কনফিগারেশন-গেটেড)
- `backend/.env`: `GOOGLE_CLIENT_ID/SECRET`, `FACEBOOK_APP_ID/SECRET`, `OAUTH_API_ORIGIN` (ভিন্ন হোস্ট হলে)।
- কনফিগার্ড না থাকলে লগইন পেজের বাটন disabled + টুলটিপ; ব্যাকএন্ড 503 দেয় — ক্র্যাশ নয়।
- ফ্লো: বাটন → `GET /auth/oauth/:provider/start` → প্রোভাইডার → `callback` → state(HMAC) যাচাই → one-time কোড → `/auth/callback` → `POST /auth/oauth/exchange` → টোকেন localStorage → role-ভিত্তিক রিডাইরেক্ট।
- একই ইমেইলের লোকাল অ্যাকাউন্ট স্বয়ংক্রিয়ভাবে লিংক হয় (ডুপ্লিকেট নয়)।
